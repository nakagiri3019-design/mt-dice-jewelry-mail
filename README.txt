M.T DICE ジュエリー加工管理システム 実用版 v2

ローカル起動:
1. pip install -r requirements.txt
2. python app.py
3. http://127.0.0.1:8300 を開く

ログイン:
ID: admin
PW: demo1234

Render設定:
Build Command: pip install -r requirements.txt
Start Command: gunicorn app:app

v2機能:
- SQLite保存
- ログイン
- 取引先マスター（締日・入金サイト）
- 預り品登録
- 検索・絞り込み
- 加工ステータス変更
- 削除
- 納品・請求管理
- メール・連絡履歴
- ファイル添付
- 提出用レポート
- CSV出力
- PDF出力/印刷
